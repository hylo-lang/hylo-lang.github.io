## GitHub Actions

The [setup-hylo](https://github.com/hylo-lang/setup-hylo) action makes it
straightforward to install a cached version of the compiler. Pin an explicit
version so your builds stay reproducible:

<Code lang="yml" code={setupHyloWorkflow} />

It works on Linux, macOS and Windows runners, on x64 and arm64. Releases are built
on macOS 26, so use `macos-26` or newer for macOS jobs.

## Other CI systems

On runners without a dedicated action, download and extract a release archive as
described in the [installation guide](/docs/user/installation/). GitHub's runners
already have `clang` available; elsewhere you may need to install it, since `hc`
uses it to link executables.
